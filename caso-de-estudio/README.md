# Caso de estudio del rebrand

Página única, al estilo Behance, que presenta el rebrand de Mooza: punto de partida, referentes, grilla, color, tipografía, logo, carteles, fotografía, Instagram, web e ilustración.

- `index.html` es la página completa; se abre directo en el navegador. Usa la fuente Geist desde Google Fonts.
- `img/` tiene las imágenes. Las de carteles, formatos, feed, fotos y carrusel salen de `components/grid/poster.js`; las capturas de la web, de `guidelines/web.html`.
