# Caso de estudio del rebrand

Página única, al estilo Behance, que presenta el rebrand de Mooza con muy poco texto: grilla, color, tipografía, logo, carteles, el logo como fondo, fotografía, ilustración, poleras e Instagram.

- `index.html` es la página completa; se abre directo en el navegador. Usa la fuente Geist desde Google Fonts.
- `Rebrand-Mooza.pdf` es la misma página en una sola hoja larga.
- `img/` tiene las imágenes. Las de carteles, formatos, feed, fotos y carrusel salen de `components/grid/poster.js`.
- Confirmar los derechos de las fotos de ejemplo antes de compartirla fuera del equipo.
