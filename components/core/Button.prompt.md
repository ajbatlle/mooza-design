Mooza action button. Fully-rounded pill shape, uppercase text. Use Primary (yellow fill) for main CTAs, Secondary (yellow outline) for alternatives, Ghost for tertiary actions.

```jsx
<Button variant="primary">Explorar eventos</Button>
<Button variant="secondary">Ver agenda</Button>
<Button variant="ghost" size="sm">Cancelar</Button>
<Button variant="warm">Destacar evento</Button>
<Button variant="primary" disabled>No disponible</Button>
<Button variant="primary" size="lg" fullWidth>Ir a mooza.cl</Button>
```

Variants: `primary` (yellow fill, dark text), `secondary` (yellow outline), `ghost` (white text, subtle border), `warm` (orange fill).
Sizes: `sm`, `md` (default), `lg`.
