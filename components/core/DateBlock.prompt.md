Day number + abbreviated day name block. Always the leftmost element in an EventCard row.

```jsx
<DateBlock day="20" dayName="SÁB" />
<DateBlock day="16" dayName="MAR" variant="highlighted" />
<DateBlock day="7"  dayName="VIE" />
```

Spanish day abbreviations: LUN, MAR, MIÉ, JUE, VIE, SÁB, DOM.
Use `highlighted` variant for featured (DESTACADO) events — renders yellow background.
